02 / Frame flow

본 렌더링 전에 매 프레임 생성

섀도우 아틀라스는 바인딩 비용을 줄이지만, 라이트 뷰마다 캐스터를 다시 그리는 비용까지 없애지는 않는다.

PrepareView

카메라 행렬, near/far, view frustum과 shader macro를 준비한다.

GatherVisibleProxies

현재 카메라에서 보이는 프리미티브와 mesh batch를 수집한다.

RenderShadowMaps

라이트 요청을 패킹하고 2D atlas와 cube faces에 depth를 기록한다.

UpdateLightBuffer

아틀라스 변환과 cube slice index를 라이트 데이터에 병합하고 t8~t10을 바인딩한다.

RenderLitPath

각 픽셀이 자기 라이트의 atlas 영역을 비교 샘플링하여 조명에 shadow factor를 곱한다.

04 / Implementation

요청 생성부터 Depth Pass까지

라이트 컴포넌트는 투영만 책임지고, SceneRenderer가 패킹과 실제 draw를, LightManager가 리소스와 셰이더 전달 데이터를 책임진다.

REQUEST

FShadowRenderRequest

한 번의 shadow view 렌더링에 필요한 CPU 측 명세다. CSM은 cascade마다 하나, Spot은 하나, Point는 face마다 하나가 생성된다.

struct FShadowRenderRequest {
  ULightComponent* LightOwner;
  FMatrix ViewMatrix;
  FMatrix ProjectionMatrix;
  uint32 Size;
  int32 SubViewIndex;
  int32 AssignedSliceIndex;
  FVector4 AtlasScaleOffset;
  FVector2D AtlasViewportOffset;
};
PACKING

2D Shelf Allocator

요청 크기가 큰 순서대로 한 줄에 채우고, 너비를 넘으면 다음 shelf로 내린다. 빠르고 단순하지만 빈 공간 재활용과 padding은 없다.

sortDescending(requests, by Size);
for (request : requests) {
  if (x + size > atlasWidth) nextShelf();
  if (y + size > atlasHeight) size = 0;

  viewportOffset = { x, y };
  atlasScale  = size / atlasSize;
  atlasOffset = { x, y } / atlasSize;
}
DEPTH PASS

Static + GPU-skinned caster

DepthOnly_VS.hlsl 하나를 static/skinned variant로 컴파일한다. 배치마다 world matrix와 필요 시 skin matrix SRV를 바인딩하고 DrawIndexed한다.

  • Depth test/write: LessEqual
  • Rasterizer: no-cull, DepthBias 1000, SlopeScaled 4.0
  • PCF: pixel shader 없이 DSV만 기록
  • VSM: pixel shader로 정규화 거리의 1·2차 moment 출력
TRANSFER

FShadowMapData

렌더가 끝나면 UV 변환과 품질 파라미터가 라이트별 캐시에 기록된다. 이후 Directional cbuffer 또는 Point/Spot structured buffer에 병합된다.

ShadowViewProjMatrix = View × Projection × Bias;
AtlasScaleOffset     = { scaleX, scaleY, offsetX, offsetY };
ShadowBias           = light.ShadowBias;
ShadowSlopeBias      = light.ShadowSlopeBias;
ShadowSharpen        = light.ShadowSharpen;

05 / GPU sampling

월드 좌표를 자기 Atlas 영역으로

전체 텍스처를 공유하므로 라이트별 UV 영역 변환이 핵심이다. 행렬은 0–1 shadow UV까지 만들고 Scale/Offset이 이를 atlas UV로 축소·이동한다.

shadowUV = worldPosition × ShadowViewProj
atlasUV = shadowUV.xy × AtlasScaleOffset.xy + AtlasScaleOffset.zw PCF에서는 atlasUV 주변을 비교 샘플링하고, 비교 깊이에는 constant + slope-scaled bias를 뺀다. 
// LightingCommon.hlsl — 2D atlas sample
float4 shadowCoord = mul(float4(worldPos, 1), light.ShadowViewProjMatrix);
shadowCoord.xyz /= shadowCoord.w;

float2 atlasUV = shadowCoord.xy * light.AtlasScaleOffset.xy
                               + light.AtlasScaleOffset.zw;
float slopeBias = light.ShadowSlopeBias * (1 - saturate(dot(normal, lightDir)));
float compareDepth = shadowCoord.z - (light.ShadowBias + slopeBias);
float visibility = shadowAtlas.SampleCmpLevelZero(shadowSampler, atlasUV, compareDepth);
01 · WRITE

D24 depth만 기록한다. Shadow depth pass에서는 Pixel Shader가 필요 없다.

02 · COMPARE

SamplerComparisonState와 SampleCmpLevelZero로 저장 깊이와 현재 깊이를 비교한다.

03 · FILTER

Poisson disk 최대 16탭을 평균한다. Sharpen 1은 1탭, 0은 16탭이다.

01 · WRITE

정규화 거리를 z라 할 때 RG32F에 E(z), E(z²)를 출력한다.

02 · ESTIMATE

variance = E(z²) − E(z)²를 구하고 Chebyshev 상한으로 visibility를 추정한다.

03 · SCOPE

현재 셰이딩 분기는 Spot에만 연결되어 있다. Directional과 Point는 계속 PCF 경로다.

DIRECTIONAL CSM

View-space Z로 cascade 선택

카메라 near/far를 로그·선형 혼합으로 분할한다. 현재 픽셀의 view Z로 cascade를 고르고, overlap 구간에서는 이전 cascade와 선형 보간한다. 각 cascade 중심은 texel grid에 snap하여 카메라 이동 시 shimmering을 줄인다.

POINT CUBE

방향 벡터 + cube slice index

worldPos − lightPos를 엔진/큐브맵 좌표계에 맞게 치환하고 float4(direction, LightIndex)로 TextureCubeArray를 샘플링한다. 필터 오프셋도 cube face UV에서 적용한다.

07 / Current risks

현재 구현에서 먼저 손볼 지점

아래는 설계상 가능성이 아니라 현재 코드 경로에서 직접 확인되는 동작이다. 품질과 프레임 비용에 영향이 큰 순서로 정리했다.

HIGH · CORRECTNESS

캐스터가 메인 카메라 기준으로만 수집됨

라이트 frustum이 아니라 camera frustum에 들어온 mesh만 shadow caster가 된다. 화면 밖 물체가 화면 안으로 드리우는 그림자가 누락될 수 있다.

HIGH · VSM

Spot VSM의 WorldPosition 전달 누락

VSM 생성은 request의 light position으로 거리를 기록하지만, 렌더 후 만든 FShadowMapData에는 WorldPosition을 명시적으로 채우지 않는다. 샘플 깊이와 기록 깊이의 기준이 달라질 수 있다.

MEDIUM · BLEEDING

2D 타일 사이 padding/gutter 없음

PCF가 atlas tile 바깥 texel을 읽으면 이웃 라이트의 depth가 섞일 수 있다. Border sampler는 전체 텍스처 외곽에만 적용되므로 내부 경계를 보호하지 못한다.

MEDIUM · COST

CastShadows/visibility 전에 요청을 생성

등록된 모든 Directional, Spot, Point 라이트가 요청 목록에 들어간다. 셰이딩에서는 꺼져 있어도 atlas 공간과 shadow draw 비용을 사용할 수 있다.

MEDIUM · STALE CACHE

Cube 할당 실패 시 −1이 캐시를 지우지 못함

실패 경로는 SetShadowCubeMapData(light, −1)를 호출하지만 함수가 음수 index를 즉시 return한다. 이전 frame의 slice index가 캐시에 남을 가능성이 있다.

MEDIUM · DEPTH

Point near plane 불일치

cube face 투영 행렬은 near 0.1을 쓰지만 HLSL의 비선형 비교 깊이는 0.2를 사용한다. 저장된 hardware depth와 비교식 사이에 오차가 생긴다.

MEDIUM · QUALITY MODE

VSM은 Spot에만 연결

VSM atlas와 shader variant는 존재하지만 Directional CSM과 Point shadow 샘플링은 VSM 선택과 관계없이 PCF를 사용한다. Point VSM cube 리소스는 TODO 상태다.

LOW · PERFORMANCE

정적 shadow cache 없음

라이트와 캐스터가 움직이지 않아도 전체 shadow pass를 매 프레임 반복한다. Atlas는 resource binding을 줄일 뿐 draw call 수를 줄이지 않는다.

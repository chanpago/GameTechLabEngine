한 페이지 압축 시 구성 가이드
반드시 넣을 것
1. 두 파이프라인 한 줄 요약
씬 쿼리 = 동기, 즉시 반환, 게임 코드가 제어
래그돌 = 비동기, 1프레임 지연, PhysX가 제어
2. 씬 쿼리 파이프라인 흐름도
Sweep 호출 → PhysX 실행 → FHitResult 변환 → 게임 로직
"호출부터 사용까지 같은 Tick"이 핵심 메시지
3. 래그돌 파이프라인 흐름도
에셋 인스턴스화 → 애니메이션 동기화 → 래그돌 활성화 → 시뮬레이션 → 본 갱신
"Kinematic → Dynamic 전환" + "비동기 시뮬레이션"이 핵심 메시지
4. 핵심 설계 판단 1개
FHitResult 래퍼 — "왜 PhysX 타입을 직접 쓰지 않았는가"
→ 게임 코드의 PhysX 비의존성 확보
공간 되면 추가

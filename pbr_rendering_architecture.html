Rendering Architecture

Direct-light PBRwith Blinn-Phong fallback

이 엔진의 PBR은 Forward 렌더링의 직접광에 Cook–Torrance GGX BRDF를 적용한 하이브리드 구조다. Phong 뷰 모드에서 전역 PBR 플래그가 켜져 있고 ORM 텍스처가 실제로 바인딩된 머티리얼만 PBR 경로를 사용하며, 나머지는 기존 Blinn-Phong 경로로 자동 폴백한다.

03 · MATERIAL INPUT

ORM 텍스처가 PBR의 스위치다

FMaterialInfo는 BaseColor, Normal, ORM 경로를 보관하고, EMaterialTextureSlot::ORM이 세 물성 값을 하나의 선형 텍스처로 전달한다.

R

Ambient Occlusion

현재 구현에서는 물리 기반 간접광이 아니라 단순 Ambient 항에만 곱해진다.

ambient × ao
G

Roughness

GGX 분포의 α를 결정한다. 낮을수록 좁고 강한 반사, 높을수록 넓고 부드러운 반사가 된다.

alpha = roughness²
B

Metallic

Diffuse를 줄이고 BaseColor를 F0 쪽으로 이동해 금속성 반사를 만든다.

F0 = lerp(dielectric, baseColor, metallic)
Resolution order

ORM 로딩 우선순위

  • MID 또는 머티리얼에 명시된 ORMTextureFileName
  • BaseColor → ORM 파일명 치환
  • _Diffuse → _ORM, _BC → _ORM 치환
  • 마지막 언더스코어 뒤를 _ORM으로 교체
Import caveat

FBX PBR 자동 임포트는 아님

FBX 머티리얼 로더는 Phong/Lambert 속성을 읽는다. 따라서 ORM은 MID override로 연결하거나 파일명 자동 탐색에 성공해야 한다.

또한 기존 바이너리 호환성 때문에 FArchive의 FMaterialInfo 직렬화에는 ORM 경로가 포함되지 않는다.

04 · CPU → GPU

리소스 바인딩과 상수 버퍼

렌더러는 머티리얼이 바뀔 때 텍스처 SRV와 PixelConstBuffer(b4)를 갱신한다. ORM은 타일 라이트 인덱스가 사용하는 t2를 피하기 위해 t6에 바인딩된다.

Global switch

SF_PBR → bEnablePBR

URenderSettings의 ShowFlag를 매 Draw 배치 시작 시 읽어 FPixelConstBufferType에 넣는다. ORM 연결은 그대로 유지되므로 동일한 에셋 조건에서 PBR과 Blinn-Phong을 비교할 수 있다.

Material capability

bHasORMTexture

경로 문자열만 있는 것으로 끝나지 않는다. UTexture 로드와 SRV 생성까지 성공해야 true가 된다. 즉 실제 GPU 바인딩 가능 여부를 나타낸다.

05 · UBERLIT PIXEL SHADER

픽셀 하나가 최종 색이 되기까지

PBR 경로는 Phong 셰이더 변형 안에 있으며, Normal과 ORM을 복원한 뒤 Direct Light별 PBR 함수를 호출한다.

표면 방향 복원버텍스 노멀을 기본값으로 사용하고 Normal Map이 있으면 TBN 행렬로 World Normal을 계산한다.
뷰 방향과 BaseColor 결정CameraPosition - WorldPos로 View Direction을 만들고 BaseColor 텍스처 또는 머티리얼 DiffuseColor를 선택한다.
PBR 조건 평가bEnablePBR && bHasORMTexture를 평가한다. false면 기존 Blinn-Phong 직접광 함수로 분기한다.
ORM 샘플링과 물성 변환AO, Roughness, Metallic을 읽고 Diffuse 색과 금속/비금속 F0를 구성한다.
Ambient와 직접광 누적Ambient×AO를 더하고 Directional, 타일에 포함된 Point/Spot 라이트의 Diffuse+GGX Specular를 누적한다.
Shadow와 Emissive 적용각 라이트의 그림자 계수를 곱한 뒤 Emissive와 Alpha를 더해 Scene Color에 출력한다.
타일 컬링은 PBR 모델을 바꾸지 않는다

타일 컬링은 현재 픽셀에 영향을 주는 Point/Spot 라이트 목록을 줄이는 최적화다. 선택된 각 라이트에는 동일한 PBR BRDF가 적용된다.

06 · BRDF

Cook–Torrance GGX 구성

Specular는 미세면 분포 D, 기하 감쇠 G, Fresnel F를 조합하고 마지막에 입사광과 N·L을 곱한다.

fspec = DGGX · GSmith · FSchlick / max(4(N·V)(N·L), ε)
최종 반환: LightColor × fspec × (N·L)
D · Normal Distribution

GGX / Trowbridge–Reitz

미세면 노멀들이 Half Vector 방향에 얼마나 분포하는지 나타낸다. Roughness가 하이라이트 폭과 피크를 결정한다.

α = max(roughness², 0.01)
G · Geometry

Smith + Schlick-GGX

미세면 사이의 마스킹과 섀도잉으로 인해 빛이 가려지는 비율을 근사한다.

G = G₁(N·V) × G₁(N·L)
F · Fresnel

Schlick Approximation

시선이 표면에 비스듬해질수록 반사가 강해지는 현상을 F0에서 보간한다.

F = F0 + (1-F0)(1-H·V)⁵
Metallic workflow

Diffuse와 F0 생성

diffuseColor = baseColor × (1 - metallic) + 0.02 × metallic; F0 = lerp(F0Dielectric, baseColor, metallic);

금속도가 올라가면 Diffuse는 줄고 BaseColor가 Specular 반사색으로 이동한다. 검은 금속 BaseColor에는 철/강철 계열 F0=0.56을 사용하는 휴리스틱이 있다.

Important implementation detail

현재 F0 기본값 주의

머티리얼이 있으면 비금속 F0로 Material.SpecularColor를 사용한다. FMaterialInfo의 기본 SpecularColor가 1.0이므로, 저작된 값이 없으면 일반적인 dielectric F0≈0.04보다 반사가 과도할 수 있다.

정확도를 높이려면 비금속 기본 F0를 0.04로 고정하거나 SpecularColor의 입력 범위를 명확히 관리하는 것이 좋다.

07 · LIGHT INTEGRATION

라이트 종류별 처리

세 직접광 타입 모두 동일한 GGX Specular를 사용하지만 방향, 감쇠, 그림자 계산은 라이트 특성에 맞게 분리되어 있다.

Light type방향 / 감쇠PBR 함수그림자
Directional정규화된 역 Light Direction, 거리 감쇠 없음CalculateDirectionalLightPBRCSM 또는 2D shadow map
PointLightPosition − WorldPos, inverse-square 또는 exponent falloffCalculatePointLightPBRCube shadow atlas + PCF
Spot거리 감쇠 × inner/outer cone smoothstepCalculateSpotLightPBR2D shadow atlas, PCF 또는 VSM
Ambient는 PBR 간접광이 아니다

현재 Ambient는 AmbientLight.Color × Ka × AO 형태의 경험적 항이다. 환경에서 들어오는 방향별 복사조도를 적분하는 Irradiance/IBL과는 다르다.

08 · DEBUG & COMPARISON

PBR 토글과 PBR Mask 사용법

에셋 연결을 바꾸지 않고 전체 PBR을 끌 수 있고, 별도 뷰 모드로 어떤 머티리얼이 실제 PBR 조건을 만족하는지 확인할 수 있다.

A/B comparison

ShowFlag → 그래픽스 기능 → PBR 직접광

  • ON: ORM 머티리얼은 GGX PBR
  • OFF: 같은 BaseColor/Normal을 유지한 채 Blinn-Phong
  • ORM 리소스 자체는 제거하지 않고 셰이딩 분기에서만 무시
Coverage visualization

뷰 모드 → 버퍼 시각화 → PBR 마스크

  • 초록: bEnablePBR && bHasORMTexture
  • 빨강: PBR OFF 또는 ORM SRV 없음
  • Decal은 마스크 판독을 방해하지 않도록 이 뷰에서 생략
빨간색은 원인을 구분하지 않는다

PBR Mask가 빨간색이면 “현재 PBR이 적용되지 않는다”는 뜻이다. 전역 플래그가 OFF인지, ORM 경로/로드/SRV가 누락됐는지는 머티리얼과 ShowFlag를 추가로 확인해야 한다.

09 · SCOPE & LIMITATIONS

현재 구현의 정확한 범위

Cook–Torrance를 사용한다는 점에서는 PBR이지만, 전체 장면 조명 관점에서는 완전한 물리 기반 파이프라인이 아니라 직접광 중심의 부분 구현이다.

Implemented

현재 제공

  • Metallic / Roughness workflow
  • GGX + Smith + Schlick Specular
  • Normal Mapping
  • Directional / Point / Spot 직접광
  • AO의 Ambient 적용
  • Shadow와 Tile Light Culling 연동
Not implemented

현재 없음

  • Diffuse Irradiance Map
  • Prefiltered Environment Map
  • Split-sum BRDF LUT
  • Reflection Probe / Skylight IBL
  • Screen-space 또는 Ray-traced GI
  • 물리 단위 기반 노출/톤매핑 체계
Physical accuracy

근사 및 휴리스틱

  • Diffuse 항에 1/π 정규화가 없음
  • Diffuse에 (1−F) 에너지 보존 계수 없음
  • 금속 Diffuse floor 0.02 사용
  • 검은 금속에 F0=0.56 대체
  • 비금속 F0가 Material.SpecularColor에 의존
추천 확장 순서

① dielectric F0와 energy conservation 정리 → ② irradiance cube + prefiltered environment + BRDF LUT로 IBL 추가 → ③ reflection probe와 HDR exposure/tonemapping 정리 순으로 확장하면 현재 구조를 유지하면서 완성도를 높일 수 있다.

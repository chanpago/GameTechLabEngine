⚙ System Architecture

Mundi Engine의 애니메이션 시스템은 에디터(비주얼 그래프)에서 상태 머신을 설계하고, 컴파일러가 이를 런타임 스테이트 머신으로 변환하는 구조입니다. Unreal Engine의 Animation Blueprint와 유사한 패턴을 커스텀으로 구현했습니다.

★ K2Node Inheritance Hierarchy

Mundi Engine의 모든 블루프린트 노드는 UK2Node을 상속받습니다. 애니메이션, 수학, 캐릭터 이동, 리터럴 등 카테고리에 상관없이 단일 베이스 클래스로 통일된 플랫(flat) 구조입니다. 아래 다이어그램에서 각 노드 위에 마우스를 올려보세요.

Math (8+ nodes)
산술/비교 연산. Float, Int 타입별 Add, Subtract, Multiply, Divide, Greater, Equal 등.

▢ Blueprint Node Types

에디터에서 비주얼 그래프를 구성하는 7종의 노드입니다. 모든 노드는 UK2Node을 상속하며 "애니메이션" 메뉴 카테고리에 속합니다.

AnimStateEntry
State Machine 진입점. 그래프당 1개만 존재. "Entry" 출력 핀으로 초기 상태와 연결됩니다.

Output: "Entry" (Exec)

에디터 실행 시 자동 생성. 사용자가 삭제 시 ValidateGraph()에서 재생성.
AnimState
애니메이션 상태 정의. 각 상태의 이름, 애니메이션 소스, 루프, 재생속도를 설정합니다.

Input: "Animation", "Looping", "PlayRate"
Properties: StateName, bEnableRootMotion, AnimationCutEndTime
AnimTransition
상태 간 전이 규칙. 소스 → 목적지 상태를 연결하고 전이 조건과 블렌드 시간을 정의합니다.

Input: "Execute" (Exec), "Can Transition" (Bool), "Blend Time" (Float)
Output: "Transition To" (Exec)
AnimSequence
애니메이션 시퀀스 리터럴. FBX에서 로드한 애니메이션 시퀀스를 값으로 출력하는 Pure 노드입니다.

Output: "Value" (UAnimSequence*)

에디터에서 검색 버퍼로 애니메이션 에셋을 선택.
BlendSpace1D
1D 블렌드 스페이스. 단일 파라미터(예: Speed)에 따라 여러 애니메이션을 선형 보간합니다.

Output: UBlendSpace1D*
Properties: MinRange, MaxRange, SampleAnimations[]
BlendSpace2D
2D 블렌드 스페이스. X(Direction), Y(Speed) 2축 파라미터로 Delaunay 삼각분할 기반 블렌딩.

Output: UBlendSpace2D*
Properties: MinX/MaxX, MinY/MaxY, 삼각형 수동/자동 설정
IsAnimationFinished
애니메이션 종료 확인. 루핑이 아닌 애니메이션이 끝까지 재생됐는지 확인하는 Pure 노드.

Output: "Finished" (Bool)

주로 공격, 피격 등 1회성 애니메이션 전이 조건으로 사용.

● Pin System

노드 간 데이터 흐름의 기본 단위는 핀(UEdGraphPin)입니다. 노드는 껍데기이고, 핀이 실제 연결과 값 전달을 담당합니다.

UEdGraphPin Structure

EdGraphPin.h - 핀 클래스 정의
class UEdGraphPin : public UObject
{
    uint32                   PinID;        // UUID 기반 고유 식별자
    FString                  PinName;      // "Enter", "Animation", "Can Transition" 등
    FEdGraphPinType          PinType;      // Exec, Float, Bool, AnimSequence 등
    EEdGraphPinDirection     Direction;    // Input 또는 Output
    UEdGraphNode*            OwningNode;   // 이 핀을 소유한 노드 (back-reference)
    TArray<UEdGraphPin*>    LinkedTo;     // 연결된 다른 핀들의 목록
    FString                  DefaultValue; // 연결이 없을 때 사용할 기본값
};

Pin Type Categories

Exec
실행 흐름 핀. 상태 머신의 연결 순서를 정의합니다. Entry → State → Transition 흐름 제어.
Float
실수 값 전달. PlayRate, Blend Time 등에 사용. 기본값 문자열 파싱 가능 (예: "1.0").
Bool
불리언 값 전달. Looping, Can Transition 등 조건 판단에 사용 (예: "false").
AnimSequence
UAnimSequence* 포인터 전달. AnimSequence 리터럴 노드의 출력 핀에서 사용.
BlendSpace1D
UBlendSpace1D* 포인터 전달. BlendSpace1D 노드의 출력에서 사용.
AnimPose
IAnimPoseProvider 공통 타입. AnimSequence와 BlendSpace 모두 호환 (향후 확장용).

K2Node_Animation.cpp - AnimState
void UK2Node_AnimState::AllocateDefaultPins()
{
    // 실행 흐름 핀
    CreatePin(EGPD_Input,  Exec,          "Enter");
    CreatePin(EGPD_Output, Exec,          "Exit");
    // 데이터 핀 (FAnimationState 멤버에 대응)
    CreatePin(EGPD_Input,  AnimSequence,  "Animation");
    CreatePin(EGPD_Input,  Bool,          "Looping",  "false");
    CreatePin(EGPD_Input,  Float,         "PlayRate", "1.0");
}

Exec 핀 2개(Enter/Exit)로 흐름을 제어하고, 데이터 핀 3개(Animation, Looping, PlayRate)로 상태 설정값을 받습니다. 연결이 없으면 DefaultValue("false", "1.0")가 사용됩니다.

K2Node_Animation.cpp - AnimTransition
void UK2Node_AnimTransition::AllocateDefaultPins()
{
    // 실행 흐름 핀
    CreatePin(EGPD_Input,  Exec,  "Execute");
    CreatePin(EGPD_Output, Exec,  "Transition To");
    // 전이 조건 핀
    CreatePin(EGPD_Input,  Bool,  "Can Transition");
    CreatePin(EGPD_Input,  Float, "Blend Time");
}

Exec 핀으로 From/To 상태를 연결하고, Can Transition Bool 핀에 조건 노드(Greater, Equal 등)를 연결합니다. 컴파일 시 이 핀의 평가 로직이 람다로 캡처됩니다.

K2Node_Animation.cpp - AnimSequence
void UK2Node_AnimSequence::AllocateDefaultPins()
{
    CreatePin(EGPD_Output, AnimSequence, "Value");
}

Pure 노드(실행 핀 없음). 출력 핀 하나로 UAnimSequence* 포인터를 전달합니다. AnimState 노드의 Animation 입력 핀에 연결됩니다.

ChangeState() - State Transition

AnimationStateMachine.cpp - ChangeState (simplified)
void UAnimationStateMachine::ChangeState(const FName& NewStateName, float BlendTime)
{
    if (CurrentStateName == NewStateName) return;

    const FAnimationState* NewState = FindState(NewStateName);
    CurrentStateName = NewStateName;

    Owner->SetRootMotionEnabled(NewState->bEnableRootMotion);
    Owner->SetAnimationCutEndTime(NewState->AnimationCutEndTime);

    if (NewState->Sequence)          // AnimSequence path
        Owner->BlendTo(NewState->Sequence, ...);
    else if (NewState->PoseProvider)  // BlendSpace path
        Owner->BlendToPoseProvider(NewState->PoseProvider, ...);
}

⚙ AnimBlueprint Compiler

FAnimBlueprintCompiler::Compile()는 에디터의 비주얼 그래프를 순회하여 런타임용 UAnimationStateMachine을 빌드합니다.

AnimBlueprintCompiler.cpp - Compile (annotated)
void FAnimBlueprintCompiler::Compile(
    UAnimationGraph* InGraph,
    UAnimInstance* InAnimInstance,
    UAnimationStateMachine* OutStateMachine)
{
    OutStateMachine->Clear();
    FBlueprintContext Context(InAnimInstance);

    // ========== Pass #1: State Registration ==========
    for (UEdGraphNode* Node : InGraph->Nodes) {
        if (UK2Node_AnimState* StateNode = Cast<...>(Node)) {
            // Animation pin evaluation - type dispatch
            FBlueprintValue Result = SourcePin->OwningNode->EvaluatePin(...);

            if (holds_alternative<UAnimSequence*>(Result))
                NewState.PoseProvider = Result.Get<UAnimSequence*>();
            else if (holds_alternative<UBlendSpace1D*>(Result))
                NewState.PoseProvider = Result.Get<UBlendSpace1D*>();
            else if (holds_alternative<UBlendSpace2D*>(Result))
                NewState.PoseProvider = Result.Get<UBlendSpace2D*>();

            // OnUpdate lambda: re-evaluates BlendSpace params each frame
            NewState.OnUpdate = [SourceNode, InAnimInstance]() {
                FBlueprintContext RuntimeContext(InAnimInstance);
                SourceNode->EvaluatePin(SourcePin, &RuntimeContext);
            };
            OutStateMachine->AddState(NewState);
        }
    }

    // ========== Pass #2: Entry Point ==========
    UK2Node_AnimStateEntry* EntryNode = InGraph->GetEntryNode();
    UEdGraphNode* InitialState = GetConnectedNode(EntryNode->FindPin("Entry"));
    OutStateMachine->SetInitialState(NodeToStateMap[InitialState]);

    // ========== Pass #3: Transition Rules ==========
    for (UK2Node_AnimTransition* TransNode : ...) {
        auto Condition = [TransNode, InAnimInstance]() -> bool {
            FBlueprintContext ctx(InAnimInstance);
            return EvaluateInput<bool>(TransNode->FindPin("Can Transition"), &ctx);
        };
        OutStateMachine->AddTransition({FromName, ToName, Condition, BlendTime});
    }
}

Key Design: Lambda Capture Pattern

컴파일러의 핵심 디자인 패턴은 럼다 캡처입니다. 비주얼 그래프의 닅드/핀 참조를 C++ 럼다에 캡처하여, 런타임에 전이 조건을 평가할 때 블루프린트 그래프의 닅드를 직접 재평가합니다.


이 방식으로 블루프린트 에디터에서 연결한 노드 그래프가 런타임에서도 동일하게 동작합니다.


  • Transition Condition: "Can Transition" 핀에 연결된 닅드 그래프를 매 프레임 럼다로 평가
  • OnUpdate: BlendSpace 파라미터를 매 프레임 재평가하여 실시간 블렌딩 업데이트

struct FAnimNotifyEvent
